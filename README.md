# AL-QANOON E-STAMPS — alqanoon.com.pk

Official e-stamp paper issuance, drafting & formatting — fully online for
Islamabad & Rawalpindi (twin cities). Open 24/7/365.

## The site

A single, self-contained `index.html` — no build step, no frameworks, no
dependencies beyond Google Fonts (with system-font fallbacks). Deploy it to any
static host (cPanel, Netlify, Vercel, GitHub Pages, S3…) by uploading the one
file.

### Highlights

- **Sales funnel layout**: hero → how it works → documents → pricing →
  WhatsApp order builder → trust/FAQ → final CTA.
- **WhatsApp checkout** (+92 337 4841818): the order form pre-fills a WhatsApp
  message with purpose, city, stamp value and name via `wa.me` link.
- **Micro animations at 60 fps**: scroll reveals, floating stamp card, marquee,
  animated counters, hover lifts — all `transform`/`opacity` only, with
  `prefers-reduced-motion` support.
- **Old-technology friendly**: ES5 JavaScript, `IntersectionObserver` with a
  graceful fallback, native `<details>` FAQ, system font fallbacks.
- **Fonts**: Fraunces (headings) + Inter (body).
